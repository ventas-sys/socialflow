Setup — pasos para activar
⚡ Opción A: open-wa (rápido, mientras esperás Meta)
  1. Desplegá el bridge de openwa-bridge/ en Railway o Fly.io (ver README en la carpeta)
  2. En Vercel, agregá variables: WA_PROVIDER=openwa, WA_BRIDGE_URL=https://tu-bridge.up.railway.app, WA_BRIDGE_SECRET=string-random
  3. Abrí https://tu-bridge.up.railway.app/qr y escaneá el QR con WhatsApp del número de empresa
  4. Volvé acá y probá con "Enviar mensaje real"
✅ Opción B: Meta Cloud API (oficial)
  1. Esperá la verificación de tu negocio en business.facebook.com
  2. Una vez aprobado, en Meta → WhatsApp → API Setup vas a tener: phone_number_id, access_token, business_account_id
  3. En Vercel agregá: WA_PROVIDER=meta, WA_META_PHONE_NUMBER_ID, WA_META_ACCESS_TOKEN, WA_META_VERIFY_TOKEN=tu-string-secreto
  4. En Meta → WhatsApp → Configuration apuntá el webhook a https://tu-vercel.app/api/wa/webhook con el mismo verify token
  5. Suscribite al evento messages
